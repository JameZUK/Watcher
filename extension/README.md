# Watcher browser extension

Adds a toolbar button that opens your Watcher "new monitor" form pre-filled with
the current tab's URL.

## Install (unpacked)
1. Open `chrome://extensions` (or `edge://extensions`).
2. Enable **Developer mode**.
3. **Load unpacked** → select this `extension/` folder.
4. Click the toolbar icon, set your Watcher URL once, then "Set up monitor".
